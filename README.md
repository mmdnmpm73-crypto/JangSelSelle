# مدرسه تمدن | کلاس ۷۰۱ — نسخه آنلاین

این نسخه همان سایت کلاس ۷۰۱ است، اما گپ آن با Socket.IO به سرور متصل است؛ بنابراین کاربران روی گوشی‌های مختلف پیام‌ها را تقریباً لحظه‌ای می‌بینند.

## اجرا
1. Node.js 18 یا جدیدتر نصب باشد.
2. داخل پوشه پروژه اجرا کنید:
   npm install
3. سپس:
   npm start
4. سایت روی پورت 3000 اجرا می‌شود.

## انتشار آنلاین
این پروژه برای سرویس‌هایی که Node.js را اجرا می‌کنند مناسب است. دستور Start:
`npm start`

## نکته
پیام‌ها در `chat.json` ذخیره می‌شوند و حداکثر 300 پیام آخر نگه داشته می‌شود.
